# Flow Enhanched Interpolation Network (FEIN)

This model enhances video generation from satellite imagery by incorporating wind speed, direction, pressure, and temperature data to predict cloud movement. Unlike traditional models that merely estimate motion, this approach integrates environmental factors for more accurate and realistic frame interpolation.
